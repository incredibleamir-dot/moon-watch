# moon-watch
A pygame app that predicts when the new crescent moon (hilal) will be visible at any place, for Ramadan &amp; Eid. Sky diagram, MABIMS 2023 / Danjon / Odeh criteria, NASA HORIZONS verification, 8000+ sighting database analysis, and Islamic dates (Ramadan, Eid ul-Fitr, Eid ul-Adha) for your location. Fully offline, runs with bundled vendor libs.
